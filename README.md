# Gaurav Sharma

Health systems engineer at the World Health Organization, Nepal. I build and run EHRPlus,
the electronic medical record used in 22 hospitals across Nepal.

## What I do

- **EHRPlus**: OpenMRS clinical, Odoo billing and pharmacy, SENAITE lab and PACS imaging,
  bridged into one system that hospitals use for registration through discharge.
- **Insurance and coding**: national health insurance (HIB) claims straight from the bill,
  and ICD-11 as the coded diagnosis entry.
- **Fleet operations**: releases, upgrades, monitoring and on-call for all 22 hospital servers.
- **Hospital support**: hospitals report problems over WhatsApp, and coding agents
  investigate and fix them.

## Things I've built

- **HEOC Nexus**: console for Nepal's Health Emergency Operations Centre
- **Rubric**: ICD-11 search and picker, built into the clinical UI
- **NPHL Harmonize**: antimicrobial resistance surveillance for the National Public Health Laboratory
- **EMR UI**: one component system across the EMR, lab, PACS and ERP apps
- **PACS viewer**: DICOM imaging viewer for the hospitals
- **Fleet control plane**: Ansible plus FastAPI, managing the hospital hosts
- **Support desk**: agents log and resolve support sessions over MCP
- **dictate**: push-to-talk dictation daemon for Linux, written in Rust
- **switchyard**: one endpoint for coding agents across every subscription and API key

Most of these live in private repos.
